Difference between single threaded and multi threaded

single-Threaded : પ્રોગ્રામમાં માત્ર એક જ thread હોય છે
                  Tasks are handled one by one.
                  Example : Node.js

Multi-Threaded : પ્રોગ્રામમાં ઘણા threads હોય છે
                 Tasks can run at the same time.
                 Example : Java, C++

JavaScript is a Single-Threaded language.
It performs one task at a time
Each statement runs line by line.

Node.js is Single-Threaded(mainly), but uses Multi-Threading internally.
Node.js मुख्य रूप से single-threaded होता है। but भारी काम (file reading, database, network operations) background threads में होते हैं।

What is difference between HTTP and HTTPS? 

HTTP : HyperText Transfer Protocol
Security : ❌ Not secure
Encryption : No encryption
Data Safety : Data can be easily hacked
Port Number : 80
URL Format : http://
Use Case : Informational websites

HTTPS : HyperText Transfer Protocol Secure
Security : ✅ Secure
Encryption : Data is encrypted using SSL/TLS
Data Safety : Data is protected from hackers
Port Number : 443
URL Format : https://
Use Case : Banking, login, payment sites

🔐 What is HTTP?
HTTP एक protocol है जो browser और server के बीच data transfer करने के लिए उपयोग होता है
यह data को plain text (साधारण रूप) में भेजता है
इसलिए यह sensitive information के लिए सुरक्षित नहीं है

🔒 What is HTTPS?
HTTPS, HTTP का secure version है
यह data को encrypt करने के लिए SSL/TLS का उपयोग करता है
यह सुरक्षित है, जैसे:
            Online payments
            Login systems
            Personal data

Difference between Append vs Write

👉 writeFile:
Purani file overwrite kar deta hai

👉 appendFile:
Data add karta hai, delete nahi karta

👉 writeFile() = async (best for real apps)
👉 writeFileSync() = sync (simple use ke liye)

Difference between Write and Append :

| Term       | Meaning                                                                                  |
| ---------- | ---------------------------------------------------------------------------------------- |
| **Write**  | File mein data **overwrite ya create** karta hai. Purana content **delete ho jata hai**. |
| **Append** | File ke **end mein data add** karta hai. Purana content **preserve** hota hai.   
        |
| Operation | Async Method      | Sync Method           |
| --------- | ----------------- | --------------------- |
| Write     | `fs.writeFile()`  | `fs.writeFileSync()`  |
| Append    | `fs.appendFile()` | `fs.appendFileSync()` |

5. Difference between Write & Append 

| Feature | Write                                 | Append                                 |
| ------- | ------------------------------------- | -------------------------------------- |
| Kaam    | Purana content **delete**, naya likho | Purana content **safe**, naya add karo |
| Method  | `writeFile`                           | `appendFile`                           |
| Example | `"Hello"` → `"World"`                 | `"Hello"` → `"Hello\nWorld"`           |

6. Summary
Write = File banaye ya purana delete karke likhe
Append = File ke end me naya data add kare
Read = File ka content padh le
Update = File ka content modify kare (read + write)


🔹 1. Write (File likhna)
Kaam: File ke andar naya data likhta hai.
Important: Agar file pehle se hai, to purana content delete ho jata hai.
Code (Async):
const fs = require('fs');

fs.writeFile('test.txt', 'Hello World', (err) => {
    if(err) console.log(err);
    else console.log('File likh di!');
});
Example:
File me pehle "Hi" tha → ab "Hello World" ho gaya

🔹 2. Append (File me data add karna)
Kaam: File ke end me naya data add karta hai, purana content safe rahta hai.
Code (Async):
fs.appendFile('test.txt', '\nThis is new data', (err) => {
    if(err) console.log(err);
    else console.log('Data add kar diya!');
});
Example:
File me pehle "Hello World" tha → ab "Hello World\nThis is new data" ho gaya

🔹 3. Read (File ka content padhna)
Kaam: File ke andar kya likha hai wo padh leta hai.
Code (Async):
fs.readFile('test.txt', 'utf8', (err, data) => {
    if(err) console.log(err);
    else console.log(data);
});
Output: File ka content console me dikhega 

🔹 4. Update (File ka data change karna)
Kaam: Purane content ko change karna.
Steps:
File read karo
Data modify karo
File me write karo
fs.readFile('test.txt', 'utf8', (err, data) => {
    if(err) return console.log(err);

    let newData = data.replace('Hello', 'Hi');  // Hello ko Hi se replace
    fs.writeFile('test.txt', newData, (err) => {
        if(err) console.log(err);
        else console.log('File update ho gayi!');
    });
});
