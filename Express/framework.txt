(1) What is NPM?
=> Node Package Manager
=> NPM is a tool used in Node.js to manage packages(libraries or modules) for your project.

=> It helps : Install libraies, Share code, Manage dependencies


Package Installation : npm install package-name

install karva mate
Express ne install karva => Terminal ma => npm i express or npm install express
ama color ne install karva => Terminal ma  => npm i color or npm install color

uninstall karva mate
color ne uninstall karva => Terminal ma => npm uninstall color

| Command         | Work                 |
| --------------- | -------------------- |
| `npm init`      | Create project setup |
| `npm install`   | Install packages     |
| `npm uninstall` | Remove packages      |
| `npm update`    | Update packages      |
| `npm start`     | Run project          |


(2) What is package.json?
=> It is a file that stores: Project name, Version, Dependencies, Scripts
=> Example :

  "version": "1.0.0",
  "dependencies": {
    "express": "^4.18.2"
  }
